# Proyecto Backend con Express y TypeORM

Este es un proyecto backend utilizando **Express.js** como framework para la API y **TypeORM** como ORM para interactuar con la base de datos (Oracle).

## Requisitos

- Node.js (v18 o superior recomendado)
- Base de datos Oracle (o cualquier base de datos compatible con TypeORM)
- Editor de código (recomendado: [VSCode](https://code.visualstudio.com/))
